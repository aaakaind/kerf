### New in 0.2

KERF now stands on proven open-source engines wherever one exists under a licence it can ship:

- **CAD** — a real constraint sketcher on FreeCAD's PlaneGCS solver (coincident, horizontal, vertical, parallel, perpendicular, equal, tangent, midpoint, point-on, fix; distance, radius, diameter and angle dimensions driven by `#variables`, live degrees-of-freedom readout). STEP import through OpenCascade, combinable with your own features.
- **Mesh** — exact, watertight booleans on Manifold; Rhino `.3dm` import (rhino3dm); GPU path-traced renders (three-gpu-pathtracer).
- **Layout** — fonts embedded and subset in PDF export with real kerning and searchable text; TeX hyphenation; place pages from PDFs (PDF.js).
- **Vector** — image trace, offset path, outline stroke, DXF import and export for laser cutters and CNC.
- **Everywhere** — Windows, Linux and Android apps; the AKA IND maker's mark in the app.

What is still missing is listed honestly in the README under *Honest status*.

### Privacy

The desktop apps serve KERF from inside the package and open outside links in your browser. The Android app refuses every request that is not one of its own bundled files. No analytics, no updater, no account — on any platform.
